# 针织服装 ERP 设计预览

独立静态设计原型，使用自行绘制的 SVG 图标，无外部依赖。

- `index.html`：PC 后台，默认打开款号列表，包含开发、打样、BOM 和基础资料设计。
- `sales.html`：销售端 V12，按 iPad 触控交互设计，包含产品、客户、订单、销售开单、采购单、退货、库存、成产跟单、数据分析、配货职工、扫码、系统设置 12 类导航。
- `assets/sales-v8.js`、`assets/sales-v8.css`：销售端交互与视觉样式；图标、服装图和成员插画均以原创 SVG 绘制。

页面数据为演示数据。表单修改只存在当前浏览器页面会话，刷新即还原；没有真实登录、数据库、摄像头或业务接口连接。支持示例 CSV 下载及浏览器打印。客户进度链接只演示虚构数据；正式分享需要服务端授权、有效期和撤销控制。

可体验产品上下架、下架规则试算、客户收款、客户订单独立详情、色码矩阵开单、独立退货登记与质检、盘点批次、颜色纠错、智能报单人工确认、提成复核锁定、条约编辑及来源查询。生产开发、打样、BOM 仍在 PC 后台。

## 托管

GitHub Pages 从 `main` 分支根目录发布。页面间使用相对链接，可部署在仓库路径下。

原始 PRD、本地视觉伴侣密钥和旧版设计稿不包含在此仓库内。

销售单默认打开单据列表，新增采购单入口；销售、采购和客户订单支持批次、明细、挂单、汇总、欠货五种视图，以及日期、批次、往来方、店员、门店、履约状态、预付款和分享筛选。导出继承当前查询条件与视图。

登录入口：`login.html`。首次访问销售或 PC 页面进入演示登录，账号密码可留空，不验证、不保存、不发送；仅用当前标签页会话标记控制引导流程，不属于身份认证或安全防护。销售端右上角可退出演示，客户进度演示链接不受登录引导影响。

销售端 iPad 交互：44px 以上按钮触控目标、iPad 横竖屏侧栏常驻、单据筛选侧边面板、左右滑动列表及固定单号/详情列、尺码数量加减、固定底部合计和提交、输入框数字键盘提示及安全区适配。`assets/ipad-workspace.css` 与 `.js` 提供触控适配。

V12：销售开单支持按款号/名称搜索、分类选款、多颜色与 S/M/L/XL 色码数量、每码加一、单款修改与移除、多款合单。新建单据保存真实选中行，详情、按明细查、款号搜索和 CSV 导出保持一致。色码可售量为按货品总量拆分的演示库存，不连接真实库存接口。销售端顶部标题、说明区和统计卡统一压缩，优先展示业务内容。

按订货开单：销售开单页签展示客户订货及色码欠货，支持分批发货和全部核销。确认实发后生成关联销售单，更新示例色码库存、订单累计已发与剩余欠货；已完成订单不重复核销。来源订单可在销售明细及 CSV 中追溯。所有演示状态仍仅在当前页面会话有效。
